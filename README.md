# IsiVoltPro Herramientas V2

Reconstrucción limpia de la aplicación de gestión de herramientas, QR y NFC.

## Principios

- Código independiente de las versiones RC anteriores.
- Sin datos de demostración ni técnicos precargados.
- Diseño claro y coherente con el ecosistema IsiVoltPro.
- Persistencia local aislada mediante `isivoltpro-herramientas-v2:data`.
- Flujos iniciales: herramientas, técnicos, préstamos, devoluciones, QR, NFC e historial.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run check
npm run build
```

## Estado

Versión `2.0.0-alpha.1`. La aplicación antigua permanece intacta en sus ramas y commits anteriores.
