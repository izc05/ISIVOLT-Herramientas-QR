# IsiVoltPro Herramientas 2.0.0-alpha.4

## Publicación aprobada

La nueva versión sustituye a la interfaz anterior en GitHub Pages.

## Flujo principal

- Alta individual de técnicos.
- Credencial QR personal por técnico.
- Identificación mediante QR, NFC o código manual.
- Modo administrador y modo autoservicio.
- Préstamo o devolución por lote.
- Escaneo múltiple de herramientas y material.
- Confirmación única de toda la operación.
- Registro individual de cada artículo unido por un identificador de lote.

## Compatibilidad

- Cámara QR cuando `BarcodeDetector` esté disponible.
- Lectores QR USB/Bluetooth mediante el campo de código.
- Lectura Web NFC en navegadores Android compatibles y bajo HTTPS.
- QR personal como credencial universal recomendada.
