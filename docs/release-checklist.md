# Lista previa al piloto

## Aplicación pública

- [ ] GitHub Pages responde por HTTPS.
- [ ] La PWA se instala en Android.
- [ ] El acceso directo aparece con icono IsiVoltPro.
- [ ] En iPhone se puede usar Añadir a pantalla de inicio.
- [ ] La actualización de versión sustituye correctamente la caché anterior.

## Dispositivo administrador

- [ ] Almacenamiento local disponible.
- [ ] Cámara autorizada.
- [ ] Lectura QR correcta.
- [ ] Exportación JSON y CSV correcta.
- [ ] Impresión de credencial y etiquetas correcta.

## Dispositivo técnico

- [ ] Inicio de sesión con cuenta técnica.
- [ ] Solo aparece Mi material y acciones permitidas.
- [ ] Préstamo en autoservicio.
- [ ] Devolución en autoservicio.
- [ ] Funcionamiento offline y sincronización posterior.

## Backend

- [ ] Migraciones aplicadas en PocketBase.
- [ ] Cuenta administradora inicial creada.
- [ ] Cloudflare Tunnel operativo mediante HTTPS.
- [ ] Prueba `/api/health` correcta desde móvil y ordenador.
- [ ] Creación y desactivación de cuentas comprobada.
- [ ] Copia de seguridad de `pb_data` programada.

## Piloto mínimo

- un administrador;
- dos técnicos;
- dos dispositivos móviles;
- un ordenador;
- entre diez y veinte artículos;
- préstamo múltiple;
- devolución parcial;
- pérdida y recuperación de conexión;
- revisión del historial y las alertas.
